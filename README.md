# Jess For You Café website concept

Independent Fieldwork Web demo. No affiliation, restaurant ordering system, or customer-data collection is implied. The layout and lettering are original to the concept. All café photos are representative stock photographs.

## Business details

- Town of Erin directory (business name, address, baked goods, takeout, catering, Facebook): https://www.erin.ca/doing-business-here/business-resources/business-directory/jess-for-you-cafe-and-baked-goods
- Wellington County directory (breakfast, lunch, take-home dinners, kitchen details, Facebook menu updates): https://www.wellington.ca/business-development/business-directory/jess-you-cafe-and-baked-goods
- Local skating club sponsor page (specific baked goods and the weekly Food Box): https://www.hillsburgherinsc.com/sponsors

The directories list different phone numbers. Current hours, prices, and daily availability should be confirmed with the café before a production launch.
